| | |
|---|---|
| **Role** | Domain controller, DNS, DHCP |
| **OS** | Windows Server 2022 Standard *(example)* |
| **IP** | 10.0.20.10 (VLAN 20), static |
| **Host** | VM on HV01 |
| **Specs** | 2 vCPU / 4 GB RAM (static) / 60 GB disk |
| **Installed roles** | AD DS, DNS Server, DHCP Server |
| **FSMO roles** | Schema Master, Domain Naming Master, PDC Emulator, RID Master, Infrastructure Master |
| **Global Catalog** | Yes |
| **Backup** | Windows Server Backup, nightly System State + critical volumes to NAS01 |
| **Last reviewed** | 2026-11-03 |

## Configuration summary

- DNS: AD-integrated zones, forwarders to `<UPSTREAM DNS>`. See [dns-dhcp.md](../services/dns-dhcp.md).
- DHCP: failover partner DC02. See [dns-dhcp.md](../services/dns-dhcp.md).
- NTP: authoritative time source (PDC emulator). Syncs to `pool.ntp.org`.
- Local admin: built-in Administrator renamed/disabled per baseline *(optional)*.
- DSRM password: stored in `<PASSWORD MANAGER ENTRY>`. **Not in this repo.**

## Verification commands

```powershell
dcdiag /q                       # quiet: only prints failures
repadmin /replsummary           # replication health
netdom query fsmo               # FSMO role holders
w32tm /query /status            # time source and offset
Get-DhcpServerv4Failover        # DHCP failover state
```
